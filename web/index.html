Method

What this captures

Local history from the agents present in this build, as listed in the coverage table. Human-authored inputs are counted as prompts after tool results, automatic notifications and subagent instructions are excluded. Exact copied events are removed by stable ID and content signature; ambiguous forks are retained.

Charts count retained records, including repeated requests. Word counts include pasted code and context, measured before redaction.

How the text is cleaned

Local PII detection and deterministic rules scrub human messages before labeling. An opaque-token scan runs again after substitution; residual matches are withheld.

The published dataset contains telemetry and derived labels. Prompt text stays out of the site.

How the buckets work

Jev labels the underlying purpose of scrubbed prompts using neighboring requests and known project goals. Model development and fine-tuning have their own use-case bucket. Immediate task, interaction and requested autonomy are recorded separately. Feedback applies only to completed work; corrective steering is measured independently. Delegated responses are credited to the human prompt whose logged causal link launched them.

“Execute” describes requested action; it does not prove that action succeeded. Different apps retain different telemetry, so unavailable tokens and turns are left absent rather than guessed.
